# ML_apprentice_assignment

I have already created a docker image in docker hub.

--rm is optional: Docker deletes the container immediately after it finishes running


To use the Docker Image: docker pull bashirg/rep_ml:latest

Running task 1: docker run --rm bashirg/rep_ml python task_1.py

Running task 2: docker run --rm bashirg/rep_ml python task_2.py

Viewing task 4: docker run --rm bashirg/rep_ml cat task_4.py
